Improvement queue

Human judgement rules

Prefer workstreams over themes.
Use project-specific headings such as Electrical Compliance testing, SW Versioning, Cybersecurity, QMS or DoC language.
Use Current position, not a generic executive summary.
Capture where the project stands, what changed, what was agreed and what remains unresolved.
Separate open points from actions.
Only create an action where a concrete owner/request/follow-up is supported by the transcript.
Check topic evidence before writing.
The embedding classifier should build the workstream state first, then Trooper should write from that evidence rather than raw transcript fragments.
