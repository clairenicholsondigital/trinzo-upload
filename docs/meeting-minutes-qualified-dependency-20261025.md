# Qualified dependency action duplication

Scope: Meeting Minutes Agent generated Actions and its existing proof/save/export/
recovery boundaries. This is a separate opt-in class; the untimed contained-content
class and Microsoft configuration are unchanged.

## Bounded rule

`MEETING_MINUTES_AGENT_QUALIFIED_DEPENDENCY_DEDUPE_V1=1` opts new runs in. Legacy and
resumed work without the frozen policy does not adopt it. Existing contact,
bounded-survivor and contained-content candidates keep priority within the
unchanged two-pair budget. At most one dependency pair is nominated.

Both generated, unflagged, single-owner instructions must describe completing,
finishing or resolving work by the same explicit method. Shared method/object
words and sources nominate a comparison; they never authorize deletion. Both
records must have unresolved dependency timing, without dates, prior checker
verdicts, rejected timing, conflicting binding sources, conditional alternatives,
independent additional operations, unfamiliar record metadata or reviewer edits.

The retained existing dependency must contain the other complete dependency as a
literal prefix, followed only by a route/provider qualification. This deliberately
excludes competing prerequisites and same-length paraphrases. Multiple potential
survivors remain unmerged. No instruction, dependency or timing status is rewritten.

Two separately bound Microsoft reviews must independently support BOTH original
commitments, all discarded fields, and the same obligation/method/occurrence.
The second sees no earlier answer. A timing-retention claim must cite the full
existing timing wording, not merely the dependency kind. Valid uncertainty or
semantic veto is never resampled.

Only a source-bound certificate for those exact originals, complete responses,
context and final survivor can exempt different opening operations and dependency
wording. All other preservation checks remain active. Evidence unions still fit
the existing eight-source cap. Cancellation/withdrawal language in an original
cited turn holds this class for review even if the model agrees with deletion.
Unknown, missing, removed or ambiguous evidence cannot acquire approval.

The provider cannot supply the server's certificate. Whole source spans and
clause/facet mappings are regenerated and compared exactly. Existing receipt,
identity admission, persistence, public redaction, exports and Restore separate
actions paths retain complete original records. Changed wording, status, sources
or reviewer ownership invalidate the receipt. An optional failure does not undo
an independently successful existing merge.

## Reference-format finding

Some generic responses cite both a spoken-text source ID and that exact source's
speaker-metadata ID on an instruction check. The existing validator correctly
rejects metadata as spoken instruction support. For this new class only, the
reference materializer can discard that redundant metadata reference when the
SAME unit's full spoken-text reference is already explicitly present. It adds no
reference, quote or judgment, preserves the raw response, and reports adjustments.
Metadata-only support, foreign-unit metadata, unknown references and ownership
witness requirements remain rejected. The earlier contained-content contract's
behavior is unchanged.

## Qualification and limits

Private qualification used four real Microsoft requests for the saved Eakin pair
in both input orders. Both preserve the existing fuller IT dependency and its
unresolved timing status through final preservation and identity admission.
Replaying the complete saved 16-action inventory removes only that repeated row.

Five initial generic requests exposed redundant metadata references. Exact replies
were revalidated after the wire correction; only the two previously unexecuted
independent challenges for valid positives were sent. Two generic positives then
passed; separate scopes and separate methods were vetoed. Different owners and
prerequisites were mechanically excluded. The withdrawal control exposed an unsafe
positive FIRST model judgment, so this class gained the independent deterministic
source-withdrawal hold. The complete final nine-case replay retains every unsafe
control. No semantic veto was retried or changed. One attempted extra challenge
was blocked locally by the research request cap before any network call. Total
actual qualification HTTP requests: eleven. Original failures and replies remain
private and intact.

The fresh five-transcript baseline is separate evidence, not a deployment-effect
claim: Eakin's old driver pair is absent before the new reconciliation stage in
that run. This fix does not recover that missing action or close Eakin's overall
output quality. Likewise, a single renewal-letter action in the fresh Allotment
output is not attributed to a cleanup that nominated zero pairs.
