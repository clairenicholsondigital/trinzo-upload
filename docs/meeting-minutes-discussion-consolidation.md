# Discussion consolidation

Scope: the meeting-minutes agent's discussion output. Action extraction and the
existing global semantic-reconciliation feature are unchanged.

## Published safeguards

The organiser's adjacent/global merges reject incompatible polarity,
qualifications, dependencies, bounds, named-person direction, question roles and
work phases before similarity is considered. These are rejection guards, not
proof of arbitrary semantic equivalence. The older body-cleanup protections
remain in place.

Known metadata is reconciled without truncating citations or predecessor
history. Unsupported metadata, conflicting provenance, reviewer control, or
an unresolvable warning target retains the original records. Containment demotion
retains complete candidate metadata in supporting context and refuses overflow.

Four existing organiser fixtures are retained with safer expectations: warning
transfer to different wording, an extra qualification without source proof,
explicit supporting provenance, and a contained claim whose original record
previously disappeared. Compatible positive controls remain. No tests or
production cleanup paths were deleted.

## Bounded source-checked consolidation

discussionClaimConsolidation nominates at most six pairs of unflagged generated
main leaves within one heading. Each pair must share source evidence; complete
cited source units must exist and fit the bounded packet. Reviewer content,
supporting children, questions, simulation placement and unsupported metadata
are excluded.

The existing Microsoft correction transport first selects an existing survivor,
then independently verifies every sentence of both originals against the source
and survivor. No replacement prose is accepted. A point can be subsumed by a
decision only when the existing decision fully retains it. Numeric supersets are
allowed for this nomination only; ordinary numeric-equality guards remain.

An unproved condition is not a duplicate. In particular, keeping receipts and
submitting receipts must not be assumed equivalent. The saved reimbursement
example therefore remains separate under the final condition guards.

Malformed responses, missing coverage, unknown sources, service failure,
changed inputs, or failed checks keep the original records. Similarity is only
a nomination signal. Two model assessments are not a universal correctness
guarantee. The saved lock pair passed bounded checks, but independent prototype
checks did not consistently agree on source support. This feature therefore
remains disabled pending a controlled fresh-generation quality comparison.

The feature uses MEETING_MINUTES_AGENT_DISCUSSION_CLAIM_CONSOLIDATION_V1
(default 0; 1 opts in after validation). It does not enable
MEETING_MINUTES_AGENT_SEMANTIC_RECONCILIATION_V1. Each optional provider call
has a 45-second attempt budget and one attempt.

## Recovery

The private discussion quality state keeps the complete original discussion,
original records/paths, checks and source/input/final hashes. It is excluded from
public responses and from terminology/glossary rewriting.

The reviewer sees **Restore combined paragraphs** only while the saved
affected topics and source still match the sealed result. The owned,
revision-checked restore endpoint refuses concurrent generation, stale revisions,
changed source, tampered archives and edits within affected topics. It restores
only those topics, preserves unrelated edits and derived warnings, records a
normal undo snapshot, and marks affected downstream stages stale. It does not
overwrite later edits within an affected topic to obtain a restore.

## Partial-overlap prototype

discussionPartialConsolidationPrototype is assessment-only and is not called
by live generation. It can nominate repeated sentences within a row or nearby
unflagged main rows, request a source-aware rewrite, and independently assess
every original/output sentence. Its returned discussion is always unchanged.

The optional experimental mode `delete_sentences` accepts only references to
original sentences and retained covering sentences; replacement prose is not
accepted. Every affected row must remain nonempty. Cycles, dependent/quoted
wording, conditions, missing shared evidence and citation-budget overflow are
excluded. An independent deletion-equivalence check is required in addition to
complete original/output support and coverage. This is nomination and assessment,
not automatic deletion. The returned discussion is still unchanged.

Private diagnostics distinguish protected-meaning/figure loss, unsupported
originals, lost original coverage, unsupported output, invalid response contracts,
provider failures and unproved deletion equivalence. Provider callbacks receive
copies so they cannot mutate the packet or plan used for validation. These
diagnostics are not a public review verdict that a source claim is false.

The offline script scripts/meeting_minutes_discussion_repetition_audit.js reads
explicitly supplied saved JSON snapshots. It reports literal sentence counts
and record exclusions without provider/database calls, writes or source prose
in its output. It is not part of live generation.

The saved five discussions used for this phase contain zero exact repeated
sentences within main points or across points under one heading. Consequently,
no new literal-deletion publication pass is justified by those samples. This
does not mean their paraphrased repetition is resolved. Fresh-generation,
persistence and actual export acceptance are required before a future publication
path is connected; this assessment-only change does not activate one.

Validated proposals retain complete originals and source context. Proposals
exceeding the normal publication evidence budget are explicitly marked.
Validation does not mean approval for publication. Warning-aware rewriting,
claim-level evidence allocation, persistence/recovery and repeated provider
quality checks are prerequisites for a later live partial-overlap editor.

## Multi-sentence source consistency

At the meeting-agent final-generation and save boundaries,
reconcileDiscussionClauseSources repairs a generated main point only when
whole-record resolution has left primary anchors outside its citations.
Existing per-sentence resolution must independently retain every original
primary anchor. The repair reconciles only source references already present
in the record; it does not donate unrelated globally ranked source lines.
It keeps wording, primary references, warnings, supporting context and history.
Reviewer-controlled cards are excluded. Missing/ambiguous sources, unresolved
anchors and citation-budget overflow retain the original record. This is
citation consistency, not a semantic certification of all original wording.
Private original-record/check history is protected from glossary rewriting.

Saved-five replay repairs five inconsistent DITA main records with unchanged
prose. Source consistency survives the owned PATCH/GET boundary. Single claims,
decisions, actions and early candidate ranking retain their existing behavior.

## Bounded clause experiment

discussionClauseConsolidation has no live generation call site. It nominates
repeated sentences or a single trailing comma-as/because explanation within
an unflagged generated main point. It accepts only deletions of original spans,
with a retained covering unit, protected inventories, independent per-unit
source/coverage checks and a selection hash. Prefixes cannot be removed while
dependent explanations remain. Unknown metadata, warnings, supporting children,
reviewer cards, ambiguous identities and incomplete source packets are excluded.
Complete originals and topic-scoped recovery use the existing private archive.

Three real-data trials on the saved five did not approve a wording change.
The Abbott explanatory-clause candidate was declined; DITA candidates were
also declined. Revalidation of the existing-survivor Allotment lock candidate
failed independent checks. These are recorded failed acceptance gates, not
reasons to loosen validation. Neither experiment is activated, and no visible
repetition reduction or fresh-generation quality improvement is claimed.

## Validation limits

Generic counterexamples, persistence/recovery tests, existing positive cleanup
controls and saved-candidate provider checks establish bounded behavior.
Do not claim that this closes semantic duplication, mixed-subject organisation,
all parent/support repetition, or all phases/roles. A fresh five-generation
comparison remains distinct from replaying saved records.
