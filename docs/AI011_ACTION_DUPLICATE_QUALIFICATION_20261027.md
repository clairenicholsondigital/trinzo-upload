## What is a safe merge?

Two rows are candidates only when they describe the same work occurrence, not
merely the same topic, owner or source passage. An existing survivor must retain
every supported operation, deliverable, owner, recipient, amount, condition,
timing qualification and uncertainty. Warning links, rejected dates, citations,
reviewer edits, and exact original-row recovery must survive. Similarity and a
model's equivalence label are not sufficient: the existing source-grounded
coverage and independent source-verification checks must also pass. If no
existing row is complete, keep both until a separately verified union can do so.
Distinct phases remain distinct even when their wording overlaps (AI-018).
