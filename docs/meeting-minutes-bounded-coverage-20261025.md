# Bounded repetition coverage — 25 October 2026

Scope: `/meeting-minutes-agent` generated discussion/actions and their existing
save, recovery and export boundaries. No transcript-specific production strings,
Microsoft flow changes, library rewrites or cache resets.

## Supporting text

The own-parent inventory requested atomic claims but forced the complete compound
child sentence into every claim quote. Comparing each complete child sentence to
an atomic parent fragment rejected valid containment. The inventory now requests
exact atomic spans including governing qualifications. The independent challenge
still checks every full child sentence, with a single contiguous parent span.
That span must contain every independently checked atomic parent witness; atomic
child spans must exhaustively cover each sentence. Positive model verdicts cannot
override missing checks, partial sentence coverage or protected-meaning guards.

Within these quote comparisons only, `about` and `approximately` immediately
before a numeric quantity have the same approximation spelling. This does not
remove approximation, change quantities, alter stored wording or affect global
merge/timing checks. Unqualified quantities remain different.

## Action instructions

The existing opt-in contained-requirement class additionally nominates two bounded
forms: an issue brought/raised with the same recipient, and overlapping content
instructions in the same deliverable. Nomination requires generated unflagged
single-owner untimed rows, shared evidence, compatible bounded lexical shapes,
an unambiguous longer existing survivor and no timing/rejection history, guarded
conditions or unknown metadata. Similar container names nominate only; they do
not prove a shared deliverable.

The immutable reference packet declares the comparison purpose. Issue paraphrases
require `same_obligation` and independently source-supported `commitment` basis
for both originals. Content instructions require the same obligation or an
explicitly retained required component. Both independent source/retention reviews,
all facet checks, source/evidence limits and exact recovery remain mandatory.
Withdrawal in cited source text vetoes these new forms. No generated wording,
owner, warning or timing value is rewritten. The existing total pair budget and
one-contained-candidate cap remain unchanged; no new runtime setting is needed.

## Qualification and limits

Generic regression fixtures cover both input orders, stale/invalid proof,
independent veto, missing accounting, withdrawal, quantity/polarity/attribution,
unique information, conditions, owners, warnings, review history and restoration.
Private frozen-data qualification uses real source passages through the existing
approved Microsoft endpoint, never persisted to the library. Both action pairs
pass in each order, the compound child is removed, and attribution/unique ERP
controls are retained. Full-inventory replay uses captured final responses with
exact request bindings, no network, valid receipts and exact recovery.

This closes these bounded gaps, not semantic repetition generally. Multiple-owner,
warned, timed, multi-deliverable and main/main discussion cases remain protected or
outside this class. Full fresh generation varies; lower row counts alone do not
establish a causal improvement. Library drafts need regeneration to reflect fixes.
