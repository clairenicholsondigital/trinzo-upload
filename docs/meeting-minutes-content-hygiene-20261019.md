# Meeting minutes content hygiene — 19 October 2026

Scope: `/meeting-minutes-agent` and its saved drafts in the Library. This follows the human review of the ten current Library drafts. No customer transcript rules, client-specific writing preferences, historical draft rewrite or unrelated page changes are included.

## Changes and safety boundaries

- Fresh generated text loses narrowly identifiable accidental phrase repeats, standalone descriptions of conversational tone and clearly detachable tone-only tails. Mixed sentences retain the substantive clause, dates and uncertainty. Quoted wording, meaningful repetition, operational remarks and ambiguous cases remain.
- Duplicate actions can be consolidated when complete wording demonstrably survives in the retained instruction. Owner, timing, evidence and scope checks prevent conflating different responsibilities, dated occurrences, conditions, prerequisites or reported instructions. The final preservation check proves coverage again from the retained text; a removed ID alone is insufficient.
- Actual reviewer edits are marked in the editor and at the save boundary. Saving preserves their wording, classifications and intentional duplicates. Generated model output cannot award itself reviewer status. An AI edit that returns saved human wording unchanged retains that protection; explicit omissions and changed wording remain eligible for the requested edit.
- Existing presentation rules now supply the editor, Word and PDF from the same content. Summary paragraphs survive the agent PDF export through an explicit option; the separate staged page keeps its existing default. Supporting notes written by a reviewer retain the parent row needed to display them.

New generation cleanup is applied before generated content is merged with saved work, including generated suggestions and action-audit additions. It is not applied on draft reads, ordinary saves or exports. No production draft was edited or regenerated by this work.

## Evidence and verification

The read-only replay of all ten Library drafts found no changes to their existing displayed content. Applying only the new text hygiene as a diagnostic projection changed two of 428 saved text fields: an adjacent repeated phrase and a detachable lighthearted aside. The latter retained the uncertainty about the submission date. These projections were not saved.

Regression coverage includes misleading repetition, quotations, operational remarks, mixed content, ownership, conflicting timing, conditional tasks, human edits and nested notes, save/reload, AI edits, historical content and output parity. Real Word and PDF files were generated from a synthetic example and inspected for retained content. No tests were removed, quarantined or relaxed to conceal failures.

Final check counts and deployment evidence are retained in `/root/trinzo-minutes-hygiene-results-20261019`. The exact scoped test manifest and TAP logs accompany the summary there.

- Scoped regression suite: 841 passed across 59 files, no failures or skips. Existing captured model responses were read from the production checkout; no external generation was requested.
- Final affected suite after the duplicate-ID reviewer-protection fix: 322 passed, no failures or skips. This overlaps the broad run and adds seven regressions; totals must not be added together.
- Agent and Library Chromium suites: 65 passed, no failures or skips.
- Synthetic Word/PDF exports: substantive wording, owner, dependency and summary paragraph checks passed.
- JavaScript syntax checks and whitespace checks passed.

The duplicate-ID regressions cover identical model copies, different returned rows sharing an ID in either order, distinct saved rows sharing an ID, and ordinary action normalisation changing a copied owner. Protection follows the saved ID plus exact visible content and one matched occurrence, rather than an ID alone.

## Remaining limits

Ambiguous social commentary, workload and wellbeing discussion, uncertain holiday remarks and instructions involving jokes are retained. Paraphrased action repetitions whose scope, target or deadline cannot be proved equivalent are also retained. These require human judgment or a separate evaluated semantic change; broad keyword removal would risk losing meaningful minutes.

Cleanup also conservatively preserves supporting text beneath an unchanged human-written sentence returned by an AI edit. Newly generated commentary in that protected subtree can therefore remain; the protection prevents content loss but is not a complete tone filter.

Controlled browser/API tests and existing model-response captures verify application behavior. Fresh end-to-end external-model generation and a signed-in production browser journey are not covered. Existing Library drafts are intentionally not bulk rewritten.
