# Exact elected-record retention and bounded pair research

## Application correction

The source verification protocol previously asked the model to judge retention for every original, including the elected survivor itself. A recorded Abbott assessment said the source supported both rows but that neither was retained, including the identical elected row. Retention of a complete record in itself is an application-owned identity fact, not a semantic comparison.

New requests identify `selfRetentionMethod: exact-same-record-v1`. For that explicitly marked response, checks whose original reference equals the elected survivor reference omit the model's retention opinion. The app derives only this self-retention fact. Every source-support check, full-source owner witness, source ID, clause index, candidate identity, packet/input/source hash and non-self semantic retention check remains mandatory. A model retention field on these new self checks is rejected rather than silently overriding an opinion.

Explicit unresolved verdicts remain unresolved. A false source-support or other-original retention check still blocks a positive decision. Legacy responses without the marker retain their previous semantics, including genuine false self-retention vetoes. Unknown methods are rejected. No legacy response is relabelled or retried into acceptance. The marker changes the prompt/cache fingerprint; it introduces no new nomination class or runtime flag.

The source-operation certificate format remains v2 for compatibility. New exact-self certificates include their retention method in their hashed provenance. Existing certificates and receipts remain valid; no archived actions are restored or deleted by migration. The elected row is identified by its bound full-record reference, never by similar wording, common owners or shared source IDs.

## Validation

New tests reproduce the missing method support before implementation. They exercise repeated clause occurrences, actual merge/receipt revalidation, source/owner/other-row vetoes, unresolved and legacy false-self decisions, model overrides and unknown methods. Existing owner/source/certificate tests remain intact.

All 3,694 scoped meeting-minutes tests pass, with two existing skips; the meeting-agent build also passes. Three live synthetic Microsoft controls use the new response method correctly: supported equivalent work is equivalent; distinct review/send work and a completed source remain unresolved. These are new synthetic controls, not retries of real semantic vetoes.

All four recorded original-action source assessments retain their prior results after the code change: two unresolved verdicts, the signing case's missing-owner-witness rejection and Eakin's positive source assessment. All 13 recorded referee replies also preserve validation/reconstruction and all 30 unresolved group materializations. This correction removes an avoidable semantic question; it does not certify that the saved duplicate pairs are mergeable or demonstrate a visible duplicate-count reduction.

## Role and certainty research

An isolated updated source-inventory contract separates committed/uncertain/not-applicable certainty from work/qualifier/context type. Uncertain source material can be absent from a target without becoming confirmed missing work. It cannot be certified retained or disposed as context. Prompt rules distinguish speaker, addressee, assignee and deliverable recipient, and distinguish courtesy from meaningful fulfillment qualifications. No such research inventory is published as an action or new reviewer question.

Twenty-seven local contract checks pass. Ten live synthetic controls yield eight passes and two blocked positive controls. Ambiguous self-correction now preserves uncertainty, and the changed-recipient negative passes. The two positive request/acceptance cases remain blocked: the inventory classifies the original request as uncertain at the instant it was spoken despite explicit acceptance later in the supplied exchange. One retention response improperly certifies that uncertain item; the other preserves it as unclear. No acceptance rule was relaxed to pass them.

Four saved action-pair trials were bounded to one existing survivor each: Abbott's tracker and signing rows, Eakin's contact/review rows and a DITA pair with different deliverables. The source inventory sees raw cited source turns rather than either proposed action. A separate assessment checks the actual two original action descriptions using the existing per-clause/source-owner contract. Full records, warnings and original source inventories are preserved. These trials are neither nominations nor merge authority.

None qualifies for automatic removal. Blockers include a standalone neighbour-context item under the wrong focus, request/recap uncertainty judged before final acceptance, missing owner citations, conflicting context dispositions and distinct operation/deliverable checks. In particular, positive source agreement alone cannot override another failed scope, target-retention or ownership safeguard.
