# Contact-purpose comparisons

Scope: Meeting Minutes Agent Actions only. New independently captured switch:
`MEETING_MINUTES_AGENT_CONTACT_PARAPHRASE_V1=1`. Legacy work without the snapshot
stays on its captured policy. Existing class priority and total pair budget stay
unchanged; this class nominates at most one unambiguous pair.

Generated unflagged single-owner untimed instructions can nominate when a bounded
contact/clarification frame retains the same recipient and exact informative
purpose vocabulary. Nomination never proves equivalence. Two independent existing
reference-based source/retention reviews require both originals to be supported
commitments to one obligation, occurrence and recipient, and the complete retained
requirement in one unchanged existing survivor. Conditions, separate work, unknown
metadata, timing/rejection history, reviewer edits and cited withdrawal veto.

A complete response shape explicitly lists both instruction and owner checks.
Instruction-to-owner witness requirements are unchanged: missing checks or
references reject without a semantic retry. The app supplies no positive verdict
or missing reference. Coverage certificates are server-issued; provider-injected
certificates are stripped. Valid receipts and exact recovery survive identity
admission, JSON, public projection, Word and PDF. Previous proof classes retain
compatibility.

Private qualification on the latest saved contact pair passes in both orders
with four fresh Microsoft requests. Full inventory replay reduces15 to14 actions
with one candidate/two reviews, valid receipts and exact recovery. Failed earlier
contract experiments are retained separately. This is a bounded class, not a
claim that every contact paraphrase or all repeated actions are fixed.
