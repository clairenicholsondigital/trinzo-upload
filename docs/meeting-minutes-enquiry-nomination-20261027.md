# Bounded enquiry nomination

Scope: `/meeting-minutes-agent` action comparison only, under the existing
`MEETING_MINUTES_AGENT_CONTACT_PARAPHRASE_V1` switch and captured policy.

Contact-purpose parsing now recognises `follow up with … regarding/about/on …`
and `speak/talk to/with … to clarify …`. Two enquiries can nominate a comparison
when they have the same owner and recipient, shared evidence, at least four
shared purpose words and at least 40% overlap against the smaller vocabulary.
This overlap gate applies only when both rows use these new bounded forms.
The prior exact-purpose comparison remains available unchanged.

Nomination is not deletion authority. Existing protections remain: unflagged,
single-owner, untimed generated rows, bounded evidence, no conditions or separate
execution work, one unambiguous fuller existing survivor, unchanged pair budget,
two independent source/retention reviews, commitment support for both originals,
strict `same_obligation` verdicts, complete receipts and final preservation.
No client names, transcript snippets or project vocabulary are runtime rules.

This closes the demonstrated nomination gap. It does **not** establish reliable

colleague trial is claimed. No existing library drafts were rewritten.

## Regression coverage

The generic enquiry example exercises both input orders, exact survivor wording,
reversible receipts, missing proof rejection and independent source vetoes.
Protected cases include different recipients, owners and purpose, disjoint
citations, warnings, reviewer edits, unknown metadata, timing/rejection history,
conditions, extra execution work and ambiguous survivors. Historical inspection
now asserts this supported grammar nominates without making provider calls or
writing production records.
