# Source-established full-name ownership witnesses

## Bounded correction

The minutes promotion checks already had a source-speaker identity inventory, but semantic deduplication required literal owner spelling. A Teams display label could therefore be accepted by one path and fail the other. This release reuses that inventory through a full-label-only resolver in source context retrieval, independent source verification, reference/facet review, final action reconciliation and recovery-receipt validation.

The complete source inventory is the authority, rather than generated action owners, Settings inference or the selected citation window. The existing generic Teams surname-first/middle-initial rules apply only where the source establishes one eligible identity. A conflicting initial, a fully spelled middle-name identity with the same first name and surname, or a separately established shorter full-name identity prevents the alias. First-name-only labels cannot establish a full-name witness.

Alias witnesses must match a unique source ID, its original speaker label and a real passage from that unit. The scope copies the source inventory at construction. Raw speakers, transcript text, ownership values and existing action wording remain unchanged. Source hashes bind existing packets and recovery receipts to that complete inventory; changing the transcript, including adding a competing identity outside the cited window, invalidates the receipt.

The Microsoft source-review prompt lists the admitted speaker labels. Identity presence still does not establish assignment, acceptance, equivalence or retention. Independent uncertain/negative verdicts remain vetoes. Different work, recipients, timing, reviewer-authored/kept items, qualifications and all existing merge-class constraints remain protected. This release introduces no new merge class or runtime flag. Existing exact-duplicate handling retains review flags and full recovery records.

## Evidence

- Deterministic regressions exercise successful source-bound exact-duplicate reconciliation and recovery, conflicting or separate identities, incomplete/unbound/duplicate source IDs, first-name refusal, different obligations/timing, warning preservation, immutable scopes, independent source/retention refusal, reference-based review and bounded context retrieval.
- Two isolated real Microsoft tests use synthetic passages. The equivalent-task test returned `equivalent`; the different-deliverable test returned `unresolved`. Both passed response/source accounting validation. Neither touched storage.
- Read-only analysis of the saved five-run results finds 168 Abbott source turns whose existing Teams speaker identity can now witness the full action-owner name. The other four have no additional identity witnesses. This is a corrected blocker, not proof that those 168 turns contain actions, nor a count of removed duplicates. Existing library drafts are preserved.

## Grouped-action research and next boundary

The five saved outputs still have 30 unresolved accepted groups: Abbott 7, DITA 8, Allotment 8, Eakin 6, Parking 1. All report unsupported group-to-atomic mapping. Only three groups have individual referee verdicts for every listed member (two Allotment, one Parking); membership/classification does not prove complete group coverage or settle a conflicting positive group verdict. No warning is removed on that basis.

The next batch should qualify an explicit source-backed mapping contract before enabling any group handling:

1. Bind the group, complete member inventory, original source units and existing writable action candidates to one immutable request. Report truncated/missing members as unresolved.
2. Require an outcome for each individual obligation, distinguishing an existing action representing the same work from a separate task, non-action material or unresolved coverage. A group owner/timing hint never donates fields to a child.
3. Check that every mapped target exists, retains the complete obligation and qualifications, and has its own supported ownership, recipient and timing. Audit unresolved siblings separately. A positive group verdict cannot approve or reject every child.
4. Challenge covered-work judgments independently, including raw passages outside a child's focus citation. Validate complete source accounting. Keep inconsistent or unclear results for review.
5. Replay all 30 saved failures plus separate-work negatives through actual reconstruction, final preservation, save/reload and recovery. Only then test fresh generation. Keep Abbott's sparse-output guard until independently supported coverage justifies its removal.

This release does not change Microsoft configuration, generation caches or library drafts, and does not enable the previously unqualified simple-obligation research class.
