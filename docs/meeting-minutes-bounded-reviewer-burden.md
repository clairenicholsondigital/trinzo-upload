# Bounded reviewer-burden corrections

Only the Meeting Minutes Agent opts into selector protocol changes. Existing library drafts and cache are not rewritten.

* Detailed contact introductions can share an existing survivor only with identical complete instruction tails, literal recipients, owner/evidence sets, untimed status and safe metadata. Both display deduplication and final preservation use the same proof. Different purpose words, warnings and reviewer records are outside this rule.
* Timing recovery distinguishes invalid response/own quotations, unresolved binding, semantic uncertainty and supported timing. At most two targets and four additional calls share 90 seconds; each request has at most 30 seconds. Only invalid/missing/foreign-quote responses get one isolated retry. Valid uncertainty and semantic vetoes do not get resampled.
* Nominal read-back proof requires a complete original-action claim inventory, own-source witnesses, unique named owner, unchanged timing/meaning and an independent verifier. It is disabled by default pending fresh workflow validation. Private server-owned proofs are immutable through glossary normalisation and cannot be supplied by the client. Changed work, source or date invalidates them. Other source/calendar checks remain authoritative.
* The two apparently unprotected filing opportunities failed source verification. A rationale-only citation cannot establish a proposed plan; a location question cannot establish a confirmed location. Nomination remains shadow-only and no text is automatically filed or deleted.
* The gated private selector schema/prompt require KEEP/REMOVE and nonempty supporting turn IDs. Protocol-invalid rows get diagnostic retry feedback; valid decisions are never converted from extraction statuses. Both independent selectors, sample count and evidence checks remain intact. A nonce-bound terminal failure signal stops only the isolated subprocess before executor shutdown can hide the failure. A hard deadline remains distinct; up to 64 recent metadata-only diagnostic records survive failure.

Switches: `MEETING_MINUTES_AGENT_TIMING_RECOVERY_V1=0` disables isolated timing recovery; `MEETING_MINUTES_AGENT_NOMINAL_TIMING_PROOF_V1=1` enables the separately gated nominal path; `MEETING_MINUTES_AGENT_SELECTOR_PROTOCOL_V1=1` enables the separately gated private selector prompt/schema option. The selector prompt/schema changes remain disabled by default: both DITA and Abbott reached the unchanged 240-second limit during release validation, so timing reliability is not established. Failure signalling/metadata diagnostics are enabled separately without changing selection prompts. No Microsoft configuration change is required.

Targeted validation includes full final-preservation reconciliation, changed owners/recipients/purposes/timing, duplicate IDs, source/actor ambiguity, invalid timing quotes, verifier vetoes, owned saves and private-proof injection, Word/PDF export, selector local/global numbering, incomplete response retries, wrong-nonce signals and deadlines. Saved-output replay demonstrates one fewer DITA action, with original wording retained and no Discussion/filing edits. These checks do not substitute for a fresh full five-transcript output comparison. DITA's 240-second completion reliability remains open unless fresh checks complete successfully.
