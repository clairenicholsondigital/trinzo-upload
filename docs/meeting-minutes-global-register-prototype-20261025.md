# Global action-register feasibility prototype (not production)

This standalone research harness has no route, worker, provider transport, database connection or runtime flag. It is deliberately held outside the deployed repair-loop change. It prepares an immutable-hash register, full cited source context, all pairwise comparisons (including different owners and first verbs), and unresolved context. More than 100 actions fails explicitly rather than silently dropping comparisons. Missing source IDs are explicit. Current deterministic directional coverage diagnostics remain intact.

The model prompt asks for exhaustive classifications, not rewritten actions. Assessment rejects stale packets, changed register data, missing/duplicate/unexpected decisions and invalid classifications. Even unanimous equivalence cannot alter an action: all consolidation nominations require independent source verification. Reviewer-authored fields, timing decisions/history, recipients, quantities and warnings stay byte-for-byte represented in the unchanged output. This is a discovery/contract prototype, not a new automatic deduplicator.

Four generic tests pass. Offline preflight on all five saved post-PR129 outputs preserves all 57 actions and enumerates 382 within-meeting comparisons (91 Abbott, 105 DITA, 66 Allotment, 120 Eakin, zero Parking). Both known Eakin/Allotment pairs appear together despite previously being in separate referee batches. No provider calls or library writes were made. These old saved outputs are feasibility inputs, not a fresh generation or a semantic-quality result. PR130's newer evidence preservation must be used for real source-backed qualification.

Next gates before any production integration:

1. Use current normalized source packets to obtain isolated Microsoft classifications; independently verify proposed same-deliverable coverage with exact source spans and full owner/recipient/date/condition/quantity/method/occurrence checks.
2. Include adversarial examples of distinct operations on one object, different recipients, effective dates versus deadlines, dependencies, conditional work, partial overlaps, uncertainty, reviewer edits and unresolved source references. Shared owners/lines never prove identity.
3. Define a typed complete group-to-atomic mapping with the published Microsoft tool contract; retain unmapped remainder. This harness does not solve missing group materialization.
4. Reuse or extend the existing independent verifier only where evidence justifies it, with bounded proof classes. Do not lower lexical or qualifier safeguards to force the two real pairs through.
5. Qualify preservation across admission/save/reload/export and fresh held-out/five-run outputs before replacing existing reconciliation. No permanent extra production pass should be added merely because this preflight succeeds.

All-pairs enumeration is a feasibility upper bound, not a proposed 382-call production workload. Compare the whole global inventory or bounded global nominations with the same exhaustive accounting. Partial overlap/ambiguity may properly remain reviewer work.
