# Reviewing retained discussion material

Needs filing retains entries whose placement was not established. The count is a count of retained entries, not a count of proven errors.

The discussion editor supports three explicit choices:

- File an occurrence below an existing discussion paragraph.
- Move an occurrence into a discussion point under an existing or newly named topic.
- Accept an optional suggested paragraph when the existing conservative subject selector identifies one unique destination.

No choice is applied automatically. Suggestions use a complete snapshot of the public discussion, filing pool and source units. Edits invalidate the old suggestion until a fresh projection is returned. Warned entries, reviewer-owned destinations, missing citations and ambiguous matches receive no suggestion.

Exactly identical generated wording can share one display group. Each occurrence retains its own sources, warning links and filing controls. Protected metadata does not permit merging. Reviewer-owned entries remain independently displayed. Grouping does not change the backing records or the retained-entry count.

Moving a record preserves its complete text, valid supplied citations, warning references and placement/merge history. The reviewer’s placement uses the existing save, undo and redo paths. Filing one occurrence cannot remove another occurrence merely because the text and some citations coincide.

Linked warning definitions are recovered from the current draft’s durable flag collections where available. If a definition is unavailable, the existing reference receives an explicit diagnostic saying its explanation is unavailable; this is not a reconstruction of the missing warning. These entries do not receive filing suggestions. Current resolved warnings take precedence over older definitions.

Browser grouping is a display projection. Ordinary Word and PDF minutes change only after the reviewer moves content into the main discussion. Evidence exports continue to retain the individual unfiled occurrences and their source references.
