# Bounded main-point containment

A short generated main point can repeat a fact already present in a fuller main
point, even when the two paragraphs cite different turns. The existing symmetric
merge nominator requires shared citations and leaf survivors. This change adds a
separate directional nominator without changing those existing guards.

Only same-topic generated points are considered. The removable point must be an
unwarned leaf, at most 300 characters and at most 65% of the survivor's length.
The survivor must have no own warning; recognised generated supporting trees
(including their warnings) remain unchanged. Reviewer-owned topics, unknown
metadata, duplicate identities, missing/ambiguous sources, questions, simulations,
unsafe metadata unions, incompatible protected qualifiers or timing, and new
numbers are excluded. Lexical overlap only nominates; it never authorises deletion.

At most one pair is assessed per draft. Both paragraphs' citations must fit within
an 18-turn span. The evidence packet supplies the contiguous exchange plus up to
three neighbouring turns on either side, bounded to 24 units / 48 KB. Retrieved
context is not automatically added to published citations. Insufficient context
means retaining the originals, not truncating the proof.

The existing two independent source-bound proposal and clause-coverage checks
must both accept an existing permitted survivor. Every clause of both originals
must be supported and retained, including actors, scope, timing, conditions and
uncertainty. Directional responses also reject extra fields, so an unsupported-
claims declaration cannot be ignored beside a positive verdict. Invalid replies,
timeouts and vetoes preserve both originals. No prose is rewritten and no distinct
material is moved into supporting details or Needs filing.

The stage follows the bounded editor and own-parent cleanup. It runs only when
`MEETING_MINUTES_AGENT_DISCUSSION_BOUNDED_REWRITE_V1` is enabled. Set
`MEETING_MINUTES_AGENT_DISCUSSION_DIRECTIONAL_COVERAGE_V1=0` to disable just this
stage; otherwise it is enabled under that bounded-editor gate. There are at most
two optional provider calls (45-second budget each) when a candidate exists.
The broad semantic consolidation flag remains independent.

The full original tree and source hash are archived. Chaining preserves earlier
valid recovery proofs. An unchanged owned save preserves a valid server-created
consolidation's exact discussion instead of running its citations back through
the eight-reference lexical picker. This applies to existing-survivor, rewrite
and composed proofs. Client-supplied quality state cannot supply that authority.
Changes to discussion, source, date or date confirmation retain the existing
normalisation/invalidation behaviour. Exact topic hashes and source hashes still
control restoration; unrelated topic edits do not prevent restoring an unchanged
affected topic.

Validation includes generic positive and negative controls, actual owned save /
reopen / restore routes with mocked persistence, five captured workflow replays,
and three private Microsoft comparisons of the saved five-output set. The Eakin
clock/service-interval example was accepted three times: 17 main rows became 16,
with survivor wording, child warnings, nine source references and restoration
retained. Four other saved outputs nominate no pairs. This is not a fresh
extraction run or proof of zero semantic repetition. Existing library drafts are
not changed by deploying this code.

Partial overlaps with unique information on both sides, warned paragraphs,
question/answer echoes and disputed general-versus-specific scope remain separate
work. In particular the earlier Parking verifier veto is not bypassed.
