# Complete source-proof contracts

`MEETING_MINUTES_AGENT_ACTION_PROOF_CONTRACT_V2` separately captures complete
response templates for existing independently reviewed Action comparison classes.
It enables no nomination class, raises no budget and preserves existing validators.
Every source/owner/retention check starts unclear with empty references. An owner
check cannot replace the references required by each instruction check. Semantic
vetoes are not retried and missing references are never filled by the app.

Qualification also exposed an ordinary conjunction being classified as the SI
symbol for attoseconds. The shared numeric tokenizer and edit-preservation checks
are unchanged. New contained-content proof packets use an explicit versioned
facet interpretation: clear grammatical "as" is not a measurement candidate;
explicit numerical quantities, unit declarations and ambiguous standalone symbols
remain protected. Full instructions, quantities and remaining unit facets still
need source proof. Canonical unit/quantity retention guards remain active.

The facet policy is bound into new packets and server-issued certificates as
`unitContextVersion: 1`. Earlier certificates regenerate the original interpretation
without this marker, preserving existing receipts. Unknown versions fail closed.
No model-supplied certificate or facet-policy selection is trusted.

Real private qualification on a previously rejected renewal-letter pair passes
both input orders with two independent Microsoft checks each, one unchanged
existing survivor, valid receipts and exact recovery. Exact captured-request
replay reduces the complete frozen inventory from ten actions to nine. The earlier
missing-owner and false-unit failures are retained. Prior proof receipts and JSON,
public redaction, Word/PDF and recovery boundaries are checked independently.
