# Own-parent current consideration comparison

`MEETING_MINUTES_AGENT_OWN_PARENT_CONSIDERATION_V1=1` captures the optional
`presentConsideration:true` discussion policy on new agent workflows. Existing
and resumed workflows without the captured option keep the previous behaviour.

The own-parent coverage guard previously recognised active `considering` as an
uncertainty qualification but missed passive `is being considered`. An otherwise
valid inventory was rejected before the independent source challenge.

Only the own-parent proof comparison now recognises `is/are/am being considered`
against `is/are/am considering`. Each compared span must contain exactly one
consideration expression, in present progressive form. Past, perfect, future,
discontinued and compound consideration expressions remain excluded from this
new comparison. The shared discussion safety module and all its other consumers
are unchanged. This is a rejection-guard correction, not a semantic proof.

The interpretation marker is included in each candidate and packet hash. Both
complete assertion inventory and independent full-sentence/source challenge are
still mandatory. Actor, recipient, option, attribution, quantities, timing,
negation, qualifications, warnings, reviewer protection and source witness
checks remain in place. A changed option or actor must still be declined by the
source reviewers even where local signatures alone cannot distinguish meaning.

No record, quote, source or parent text is rewritten. Only a proved redundant
supporting leaf under its own unchanged parent can be removed. Existing recovery
archives retain the exact original child and parent. Provider failure, malformed
responses, stale input or a veto preserve the original output.

Qualification used private frozen outputs from all five transcripts. The Abbott
current-consideration child passed two fresh independent Microsoft reviews and
was removed with the parent and citations unchanged; exact recovery was checked.
Production library drafts and cache were preserved. This closes the bounded
qualification mismatch, not general semantic repetition.
