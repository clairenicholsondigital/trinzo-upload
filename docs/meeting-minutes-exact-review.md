# Exact duplicate reviewer checks and reconciliation guards

This release changes only the meeting-minutes agent and its review flow.

## Delivered bounded fixes

- Exact warning copies on the same explicitly linked, unique rendered occurrence/field are presented together. Equality includes every flag property except its ID; differing evidence, dispositions, metadata, reviewer authorship, notes or targets prevent grouping. Every original warning and independent control remains available. Counts stay honest.
- An explicit **Mark all N identical checks as checked** action confirms only the named copies. It validates current identity, exact content and unique target again at click time. Any unsaved review note blocks the batch action. Normal revision-guarded save, reload, undo and redo handle the transaction. Nothing is automatically resolved or deleted.
- Semantic reconciliation now protects both legacy kept-action IDs and newer occurrence IDs. Before this change only occurrence keeps reached nomination. The existing source-certified contact class supplies a positive control showing the keep tests exercise a real removal path.
- Source ownership uses the existing full-name boundary helper consistently. A longer surname/name token cannot satisfy a shorter owner's witness through a substring match. Actual full-name text/speaker witnesses remain accepted.

## Research and deliberately held work

The fresh run has 61 actions, 124 filing entries and 238 open questions. Broad semantic repetition remains open. Its narrow semantic nomination produced zero candidate pairs, despite obvious visible repetition. Timed/warned/compound actions and broader contact grammar fall outside those classes. Grouped action materialisation failures and the sparse-output fallback also preserve overlapping registers.

A separately captured simple-obligation class was prototyped and committed at 1172d313 on research/minutes-simple-obligation-20261026. It required an unchanged existing survivor, both source-supported commitments, two independent same-obligation verdicts, complete retention, full-name ownership witnesses, citation capacity and exact recovery. It exposed missing nearby ownership context, overly broad name-witness retrieval and inconsistent generic component/same-obligation instructions. Real qualification still produced inconsistent or unclear decisions. These refusals were retained; the class is not part of this release and is not enabled. We did not relax its semantic vetoes, remove citations or raise limits to obtain a passing result.
