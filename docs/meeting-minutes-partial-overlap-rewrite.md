# Partial-overlap discussion rewrite nomination (gated)

Status: release-ready bounded implementation. The new flag is disabled by default in code and enabled explicitly by the release configuration after validation.

The existing bounded editor obtains pair nominations from a deletion-oriented consolidation pass. That pass requires matching original qualification signatures, so it prevents the editor from considering partially overlapping paragraphs even when a combined paragraph could retain all qualifications. The existing deletion pass and its guards remain unchanged.

The optional `MEETING_MINUTES_AGENT_DISCUSSION_PARTIAL_OVERLAP_REWRITE_V1=1` path requires the existing bounded-rewrite feature as well. It nominates at most one additional pair, after existing candidates, within the existing three-candidate overall cap. Only adjacent generated main paragraphs in the same unprotected topic qualify. They must share at least two source IDs and all original references must lie within eight consecutive source positions. Reviewer content, descendants, warnings, unknown metadata, duplicate identities, questions, conflicting polarity, phase, bounds or figures are excluded. Existing lexical and semantic thresholds remain unchanged.

For those nominations only, the editor receives the complete local source window, up to eight units before and after the original references. Existing limits remain 24 units, 48,000 serialized characters, 12,000 characters per source unit and 12 output citations. Uncertain or oversized context declines the nomination; no citations are truncated to make an edit fit. Rewritten prose cites every source witness used by its independent claim/original/output verification. Old references remain in the complete original-row archive, with an explicit citation-allocation ledger. More than 12 verified witnesses declines the whole edit. Verified primary references are aligned with those witnesses.

The same claim-inventory, proposal and independent verification stages must approve every original claim, every original sentence and every output sentence. Additional deterministic checks prevent the new path from dropping original uncertainty markers or condition phrases, alongside the existing source-word, figure and name checks. Full originals, source proofs, identity history and topic-scoped restoration remain preserved. Source context does not authorize recovery of new facts or silent repair of an unsupported original.

An unchanged owned save preserves the complete verified paragraph and citation allocation, including proofs exceeding the lexical picker's eight-reference limit. Date, source or actual content changes continue through ordinary validation; affected edits disable automatic restoration. The existing revision, ownership and active-generation guards remain.

Validation: 32 new generic nomination/allocation regression cases; new real save/restore and Word/PDF checks; 407 relevant checks passed with two existing skips, and 417 Python checks passed. Across five saved drafts, the disabled implementation produces identical nomination packets to the previous live implementation. The enabled path nominates one previously excluded pair in one draft; the other four nominate none. Inputs were not mutated. All three real Microsoft runs of a generic explicitly supported fixture produced an accepted, fully verified rewrite. An actual accepted saved-input rewrite survives final generation hygiene, owner-scoped GET/PATCH, Word/PDF with and without references, and exact restoration, without live database writes.

The initial three real-data trials reached the editor but included a citation-overflow refusal and an original-source-fidelity refusal. Verified allocation removes the false old-plus-new citation-capacity obstacle while retaining the actual witness limit and every original reference in history. In three fresh real-data trials after allocation, one rewrite was accepted and two declined over the original follow-up assertion. Those originals remained unchanged. These are isolated saved-input trials, not fresh generation workflows. No Microsoft configuration or existing library draft was modified.

Completion is scoped to the nomination/proof mechanism: eligible partial overlaps can reach the editor, verified complete rewrites can publish/save/export/restore, and unsupported originals cannot disappear as duplication. Wider source fidelity and antecedent selection remain open; so do multi-objective action overlap and the historical referee target failures. This release does not claim that every overlapping paragraph is now combined, that unsupported original wording is corrected, or that all five historical drafts have been regenerated.
