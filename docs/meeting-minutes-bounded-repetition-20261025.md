# Bounded repetition cleanup

This release addresses three bounded Meeting Minutes Agent capabilities. Existing library drafts are preserved; new generation captures the new opt-ins explicitly.

- A narrow action-only scope can nominate at most two unflagged, untimed, same-owner instruction pairs with strongly overlapping objects. Contact enquiries keep priority, their original context selection and a separate provider batch. Unknown scopes fail closed; legacy/resumed snapshots retain their original policy. Complete nearby assignment/acceptance exchanges cannot be displaced by keyword ranking. Mandatory context overflow retains the originals.
- Positive source-verification responses must include their required full-name owner witness. The final ownership/source checks remain unchanged. For the new survivor class only, an explicit independent-witness allocation binds the final proof to the independent check's returned source IDs. All original action citations remain; tentative proposal citations are archived with the raw responses and allocation record. Citation limits and single-attempt independent verification stay intact.
- One short main point may be removed into an unchanged, fuller point in the same topic only after exhaustive claim inventory and an independent full-paragraph challenge. Exact immutable clause indexes avoid clipping qualifications or accidentally including an unrelated negative clause in a coverage comparison. Whole source turns, same-occurrence checks, full-survivor support and contradiction checks are mandatory. Additional same-transcript context is only evidence for review: a citation is added only when explicitly selected by the independent check, within the existing publication cap. Original citations and both rows remain archived.
- A separate one-pair point/decision pass reuses the existing source/coverage engine. Only the unchanged decision can survive, and it must retain the entire point. Questions, reviewer content, genuine warnings, unique supporting details and partial overlaps stay protected. The point-only writer is unchanged.

The two new Discussion switches are frozen per generation and included in speculative fingerprints and private evaluation sessions. They default off for absent/legacy snapshots. Internal policy and proof fields remain private. All new edits compose with earlier recovery audits and the existing owned, revision-checked restore flow.

## Limits

This does not close general semantic repetition, filing burden, mixed-topic paragraphs or all factual corrections. Partial point/decision overlap with unresolved approval/sign-off/timing meaning remains open. The saved Parking baseline has nine unresolved publication targets; the new edit adds none and does not claim to resolve those nine. Optional provider refusal/failure retains the originals.

Release requires scoped Node/Python checks, bundle build, private qualification, preserved runtime settings/library rows and local/public smoke checks. The existing transcript-panel and phone-layout UI test failures remain separately reported. No Microsoft configuration edits or transcript-specific production rules are included.
